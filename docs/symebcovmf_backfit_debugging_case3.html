Introduction

In this analysis, I am working on debugging the backfit function for symebcovmf. When trying to run the backfit in the DSC, I ran into an error with a handful of simulations, so I will try to identify the source of those errors here.

symebcovmf_backfit_fit <- sym_ebcovmf_backfit_alt_v2(S = baltree_4pop_3$data$YYt,

                                              optim_tol = 10^(-8))

When I try to run the backfit, I get an error about missing standard errors in the EBNM solver. Based off the error, my guess is that \(v^{T}Rv < 0\) and therefore the standard error is NaN. If \(v^{T}Rv < 0\), then the estimate for \(\lambda\) would be zero – I expected the refit_lambda function to catch this.

After further investigation, it does seem that the issue is due to \(v^{T}Rv < 0\), which is causing the standard error to be NaN. The refit_lambda function is not catching it because the refit_lambda function causes a change in the residual matrix, \(R\) for the next iteration, and for that new \(R\), we may have \(v^{T} R v < 0\) when this wasn’t the case for the old \(R\).

Fixing the Backfit - Part 1
